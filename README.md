# Sales Dashboard - Power BI Project

## 📊 Overview
This Power BI dashboard provides a detailed analysis of sales performance across different regions, stores, products, and time periods.

## 🚀 Features
- Total Revenue Analysis
- Average Revenue Tracking
- Country-wise Revenue Insights
- Store Ranking Visualization
- Quarterly Revenue Trends
- Product-wise Revenue Breakdown

## 🛠 Tools Used
- Power BI
- DAX
- Power Query

## 📌 Key Insights
- Asia generated the highest revenue
- Store 1 ranked highest in sales
- Revenue trends changed across quarters

## ⭐ Project Purpose
This project helps analyze sales performance and supports business decision-making.
